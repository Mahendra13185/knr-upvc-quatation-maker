# KNR UPVC Quotation Maker

## Run in VS Code
1. Extract the ZIP and open the inner project folder containing `package.json`.
2. Open Terminal > New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Included
- Unlimited separate window/door measurement rows; add, duplicate, and delete any row
- Independent measurements, units, quantities, profiles, glass, hardware and labour
- 80/90 series Heavy/Light profile defaults
- Discounts and GST calculation
- Save/edit/duplicate/delete quotations
- Customer list, PDF quotation export
- Local browser database and JSON backup/restore

## Important
The sample prices are placeholders. Set actual company details and rates under Settings before using customer quotations. Data is stored locally in this browser/device; export backups regularly. Verify all business prices and tax settings before use.
